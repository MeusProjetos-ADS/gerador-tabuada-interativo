# Gerador de Tabuada Interativo

Este é um projeto acadêmico que desenvolvi para a disciplina de Desenvolvimento em JavaScript. O meu foco foi aplicar na prática os conceitos de estruturas de repetição (loops) e manipulação do DOM.

---

## Sobre o Projeto

Para esta atividade, criei uma página web simples e interativa que cumpre os seguintes requisitos:
* Permite ao usuário inserir um número de 1 a 10.
* Calcula a tabuada de multiplicação desse número (de 1 a 10).
* Utiliza um **loop `for`** em JavaScript para realizar o cálculo.
* Exibe os resultados dinamicamente na página, manipulando o DOM.

## Funcionalidades Principais

* **Entrada de Usuário:** Implementei um campo numérico com validação (aceita apenas números de 1 a 10).
* **Cálculo Dinâmico:** A tabuada é gerada em tempo real ao clicar no botão.
* **Manipulação do DOM:** Os resultados são criados e inseridos na página sem a necessidade de recarregar.
* **Validação de Erro:** Um `alert` é disparado se a entrada for inválida.
* **Design Responsivo:** Garanti que o layout se adaptasse a telas de celular e desktop.

## Tecnologias Utilizadas

Para construir este projeto, utilizei as três tecnologias fundamentais do front-end:

* **HTML5:** Para a estrutura semântica da página.
* **CSS3:** Para a estilização, cores, fontes e layout.
* **JavaScript (ES6+):** Para a lógica, interatividade, captura de eventos e o cálculo.

## Como Executar o Projeto

Como este é um projeto de front-end puro, não há necessidade de instalação.

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/MeusProjetos-ADS/gerador-tabuada-javascript.git
    ```

2.  **Abra o arquivo:**
    Navegue até a pasta do projeto e dê um clique duplo no arquivo `index.html`. O projeto será aberto no seu navegador padrão.
